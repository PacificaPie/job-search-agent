# L3 招呼语 / 触达文案质量 Rubric（LLM-as-judge）

评估对象：为某岗位生成的打招呼语（BOSS 中文）或 outreach message（LinkedIn 英文）。

每维 0-2 分，总分 10。任一「一票否决」命中则直接 fail。

## 一票否决
- **编造事实**：出现候选人材料（archive.md / 简历）中不存在的经历、数字、学校、公司。
- **语言不匹配**：BOSS 岗位输出非中文，或 LinkedIn 岗位输出非英文。（当前系统已知缺陷：LinkedIn 岗位会拿到中文固定招呼语，此项预期 fail。）
- **泄露隐私**：出现手机号、身份证号或内部数据。

## 评分维度
| 维度 | 0 分 | 2 分 |
|---|---|---|
| 岗位针对性 | 通用模板，换个岗位也能发 | 至少引用 1 个该 JD 特有的职责/技术点并与经历挂钩 |
| 证据具体性 | 只有形容词（"能力强"） | 每个主张背后有可展开的具体经历 |
| 长度与密度 | <50 或 >200 字（中文）；信息稀释 | 80-150 字，每句都有信息量 |
| 语气 | 卑微恳求或油腻夸张 | 平等、专业、有明确的下一步（CTA） |
| 可读性 | 一整段糊在一起 | HR 3 秒能抓到"是谁+凭什么+想干嘛" |

## Judge 提示词骨架
以资深招聘顾问身份，先检查一票否决项（对照候选人材料逐句核实事实），再按五维打分，输出 JSON：
{"veto": null | "<命中项>", "scores": {...}, "total": <0-10>, "worst_dimension": "...", "fix_suggestion": "..."}

## 现成种子样本
- data/reachout.db 中 4 条 drafts（同一条固定招呼语），可作为 baseline：预期得分约 6-7（针对性 0 分——它是固定文案，对任何岗位都一样）。
- 这正是「固定招呼语 → 按 JD 生成」升级是否值得做的量化依据。
